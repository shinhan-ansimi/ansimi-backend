# 실제 데이터 검증 리포트 (이슈 #12)

AI 실데이터가 적재된 뒤, `docs/test_routes.json`의 20개 경로로 `/api/routes/recommend`를
실제 호출해 그 결과를 이 표에 채운다. 좌표는 아직 가짜 시범 지역(강남) 기준이라, 실제
시범 지역이 확정되면(이슈 #27) `docs/test_routes.json`을 그 지역 기준으로 재생성하고 이
리포트도 다시 채운다.

## 실행 방법

1. AI 실데이터가 `risk_grid`에 적재되어 있고, `service_area`가 확정된 지역으로 설정되어
   있는지 확인한다.
2. `docs/test_routes.json`의 각 경로(`origin`/`destination`)로
   `POST /api/routes/recommend`를 순서대로 호출한다.
3. 매 호출의 응답(`candidates`, `recommendedIndex`)과 `route_request.elapsed_ms`를
   아래 표에 채운다.

## 완료 조건 체크 (슬라이스 11 / 이슈 #12 기준)

- [ ] 20개 중 18개 이상에서 서로 다른 후보 2개 이상
- [ ] 평균 응답 3초 이내 (`route_request.elapsed_ms` 기준)
- [ ] 추천 규칙(우회 1.2배 이하, 최저 위험) 위반 0건
- [ ] 백엔드 개발 명세 10장 완료 체크리스트 전부 체크

## 참고

- 이슈 #25에서 mock 데이터(159,253행) 기준 성능은 이미 확인함 — 평균 374ms, 최대
  1072ms(`docs/risk_grid_perf_check.md`). 실데이터로 바뀌어도 row 수·공간 분포가
  같다면 이 범위를 크게 벗어나지 않을 것으로 예상.
- 일부 경로는 직접 걸어보며 색상 구간(GREEN/YELLOW/RED)이 체감과 맞는지 판단이
  필요하다(개발 명세 1장 HITL).
